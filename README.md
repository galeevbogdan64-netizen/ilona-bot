# Бот-поисковик заказов

Каждые 20 минут бот проверяет публичные ленты фриланс-бирж и Telegram-каналов. Он отбирает заказы под твои навыки, считает, какую цену предложить, и:

- присылает тебе в **Telegram** сообщение: название, цена, насколько подходит, ссылка;
- обновляет ленту `docs/orders.json`, которую показывает приложение **«Ilona»** → «Работа».

Бот работает бесплатно на **GitHub Actions**, свой сервер и включённый компьютер не нужны.

## Где ищет (версия 1)

| Источник | Как | Статус |
|---|---|---|
| FL.ru — «Программирование» | официальная RSS-лента | ✅ проверена |
| FL.ru — все проекты | официальная RSS-лента, фильтр по навыкам | ✅ |
| Публичные Telegram-каналы | открытая веб-версия `t.me/s/канал` | ✅ впиши каналы в `config.yaml` |
| Любые RSS | список `extra-rss` в `config.yaml` | ✅ |
| Хабр Фриланс, Weblancer, Freelance.ru | публичная страница со списком | ⚠️ эксперимент |

Экспериментальные источники могут перестать работать, если сайт поменяет вёрстку. Если сайт запрещает автоматический доступ в `robots.txt`, бот его просто пропустит. Что сработало, а что нет, видно в логе каждого запуска. Kwork, Alot.pro и остальные площадки добавим в следующих версиях.

## Установка за 15 минут

### 1. Telegram-бот для уведомлений
1. В Telegram открой **@BotFather** → `/newbot` → придумай имя. Скопируй **токен**.
2. Напиши своему новому боту любое сообщение.
3. Открой в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id": 123456789` — это твой **chat id**.

### 2. Репозиторий на GitHub
1. Зарегистрируйся на github.com → **New repository** → имя, например `orders-bot`, **Public** (бесплатные GitHub Pages есть только у публичных) → Create.
2. **Add file → Upload files** → перетащи все файлы из архива.
   ⚠️ Папка `.github` скрытая, и некоторые системы её не перетаскивают. Проверь, что в репозитории появился файл `.github/workflows/orders.yml`. Если его нет, создай его через **Add file → Create new file**: вставь путь `.github/workflows/orders.yml` и содержимое файла из архива. То же сделай для `ideas.yml`.

### 3. Секреты
**Settings → Secrets and variables → Actions → New repository secret**:
- `TELEGRAM_TOKEN` — токен от BotFather
- `TELEGRAM_CHAT_ID` — твой chat id
- `ANTHROPIC_API_KEY` — *необязательно*: с ним Claude точнее оценивает заказы, раз в неделю генерирует 20 новых бизнес-идей, а каждый день — 3 новых урока для раздела «Саморазвитие»

Секреты никто не видит, даже в публичном репозитории.

### 4. Права и публикация ленты
1. **Settings → Actions → General → Workflow permissions** → *Read and write permissions* → Save.
2. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/docs` → Save.

### 5. Первый запуск
**Actions → «Поиск заказов» → Run workflow.** Через минуту открой запуск и посмотри лог: там видно, сколько заказов дал каждый источник и что подошло.

### 6. Подключение к приложению «Ilona»
«Работа» → «Подключение бота» → адрес:
```
https://<твой-логин>.github.io/orders-bot/orders.json
```
Сохрани и нажми «Проверить новые заказы».

## Настройка — `config.yaml`
- `profile` — ставка, минимальная цена, порог «подходит», порог уведомлений.
- `skills` — что ты умеешь и какие слова это выдают. Добавляй свои.
- `exclude` — слова, при которых заказ отбрасывается.
- `sources → telegram → channels` — впиши имена публичных каналов с заказами (то, что после `t.me/`).
- `sources → extra-rss → urls` — любые дополнительные RSS-ленты.

Файл можно править прямо на GitHub (иконка карандаша). Изменения подхватятся при следующем запуске.

## Запуск на своём компьютере (вместо GitHub)
```bash
pip install -r requirements.txt
export TELEGRAM_TOKEN=... TELEGRAM_CHAT_ID=...
python bot.py --dry       # только показать найденное
python bot.py --loop 20   # работать постоянно, проверка раз в 20 минут
```
Проверка без интернета на тестовых лентах: `python tests/test_bot.py`.

## Важно знать
- Расписание GitHub Actions иногда запаздывает на 5–15 минут, это нормально.
- Репозиторий публичный: лента заказов и `config.yaml` видны всем, секреты — нет.
- Бот только читает открытые ленты и раз в 20 минут делает по одному запросу на источник. Не ставь интервал меньше: это лишняя нагрузка на сайты.

## Уведомления и их включение/выключение

Бот пишет в Telegram три вида сообщений:

| Что | Когда | Команда |
|---|---|---|
| 🆕 Новые подходящие заказы со ссылкой и ценой | каждые ~20 минут, если есть новые | `/orders_on` · `/orders_off` |
| 🧠 Напоминание и урок дня | каждое утро | `/lessons_on` · `/lessons_off` |
| 💡 20 новых идей недели | по понедельникам | `/ideas_on` · `/ideas_off` |

`/all_on`, `/all_off` — всё сразу, `/status` — что сейчас включено.

**Кому приходят.** Ники перечислены в `config.yaml` → `notify.users` (там уже есть `GaleevBogdan`). Telegram не разрешает ботам писать первыми, поэтому каждый человек один раз открывает бота и жмёт «Start». Проще всего это сделать из приложения: **Настройки → Уведомления в Telegram**, впиши имя бота и ники, нажми «Подключить». Чтобы добавить девушку, впиши её ник в приложении и добавь его в `config.yaml` (приложение покажет готовый блок для копирования).
У каждого свои переключатели: команда меняет настройки того, кто её отправил. `TELEGRAM_CHAT_ID` больше не обязателен.
Бот применяет команду при следующем запуске (раз в ~20 минут) и отвечает, что включено. Команды из чужих чатов игнорируются.
Настройки хранятся в `state/notify.json`. Напоминания об уроках и идеях приходят даже без ключа Claude API, а с ключом — вместе с заголовками новых уроков и самыми прибыльными идеями.

Проверка без интернета: `python tests/test_notify.py`.
